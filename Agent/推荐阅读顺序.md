# Agent 论文推荐阅读顺序

> 排序依据：**奠基性 / 学术影响力 / 作者与机构水平 / 实用价值 / 阅读梯度**
> 总体思路：先打基础（推理范式 → 工具调用 → 反思迭代）→ 再看系统级应用 → 然后看评估与工业落地 → 最后跟踪 2025 前沿。

---

## 第一梯队：奠基必读（推理与工具调用范式）

### 1. Chain-of-Thought Prompting Elicits Reasoning in Large Language Models
- **作者 / 机构**：Jason Wei et al. / Google Brain
- **会议 / 年份**：NeurIPS 2022
- **影响力**：⭐⭐⭐⭐⭐（万级引用，LLM 推理范式的起点）
- **核心收获**：思维链的提示工程范式，few-shot CoT 与 zero-shot CoT。
- **为什么先读**：所有 Agent 工作的"推理底座"。理解 CoT 才能理解后续 ReAct、ToT、Reflexion 的设计动机。

### 2. ReAct: Synergizing Reasoning and Acting in Language Models
- **作者 / 机构**：Shunyu Yao et al. / Princeton + Google Brain
- **会议 / 年份**：ICLR 2023
- **影响力**：⭐⭐⭐⭐⭐（Agent 领域奠基之作，LangChain 默认范式）
- **核心收获**：Agent 的最基本控制流 `Thought → Action → Observation`，工程上几乎所有 Agent 框架的雏形。
- **为什么必读**：第一次把"思考"和"行动"系统结合，奠定了现代 Agent 的执行循环。

### 3. Toolformer: Language Models Can Teach Themselves to Use Tools
- **作者 / 机构**：Timo Schick et al. / Meta AI
- **会议 / 年份**：NeurIPS 2023
- **影响力**：⭐⭐⭐⭐⭐（工具调用方向的标志性工作）
- **核心收获**：自监督生成工具调用样本的方法论，是 Function Calling 的学术原点。
- **为什么必读**：理解后续所有 Function Calling 工作的基础。

---

## 第二梯队：核心进阶（推理增强与反思机制）

### 4. Reflexion: Language Agents with Verbal Reinforcement Learning
- **作者 / 机构**：Noah Shinn et al. / Northeastern + MIT
- **会议 / 年份**：NeurIPS 2023
- **影响力**：⭐⭐⭐⭐⭐
- **核心收获**：用自然语言"自我反思"作为强化学习信号，让 Agent 拥有从失败中学习的能力。
- **为什么必读**：是 ReAct 的天然下一步，也是后续 Memento 等"经验复用"路线的源头。

### 5. Tree of Thoughts: Deliberate Problem Solving with Large Language Models
- **作者 / 机构**：Shunyu Yao et al. / Princeton + Google DeepMind
- **会议 / 年份**：NeurIPS 2023
- **影响力**：⭐⭐⭐⭐
- **核心收获**：把 CoT 从"线性思考"扩展到"树搜索 + 自评估"。
- **为什么必读**：复杂规划问题的标准武器之一，也是后来 AFlow 等工作流搜索方法的思想基础。

### 6. Measuring and Narrowing the Compositionality Gap in Language Models（Self-Ask）
- **作者 / 机构**：Ofir Press et al. / 华盛顿大学 + Allen AI + Meta
- **会议 / 年份**：EMNLP 2023 (Findings)
- **影响力**：⭐⭐⭐⭐
- **核心收获**：Self-Ask 提示策略 + 多跳问答的"组合性差距"量化。
- **为什么必读**：是 CoT → ReAct 之间的关键过渡，理论与方法兼具。

### 7. MRKL Systems
- **作者 / 机构**：Karpas et al. / AI21 Labs
- **会议 / 年份**：arXiv 2022
- **影响力**：⭐⭐⭐（早期开创性，工程影响 > 学术影响）
- **核心收获**：模块化"神经-符号"系统的早期蓝图，工具增强 LLM 的思想原点之一。
- **为什么必读**：可作为补充阅读，了解工具调用思想的源流。

---

## 第三梯队：系统级应用（让 Agent 真正"做事"）

### 8. HuggingGPT: Solving AI Tasks with ChatGPT and its Friends in Hugging Face
- **作者 / 机构**：Yongliang Shen et al. / 微软亚研院 + 浙大
- **会议 / 年份**：NeurIPS 2023
- **影响力**：⭐⭐⭐⭐
- **核心收获**：用 LLM 编排多个专用模型完成跨模态任务。
- **为什么必读**：多 Agent / 多工具协作的代表作，工程参考价值高。

### 9. Generative Agents: Interactive Simulacra of Human Behavior
- **作者 / 机构**：Joon Sung Park et al. / 斯坦福 + 谷歌
- **会议 / 年份**：UIST 2023（Best Paper）
- **影响力**：⭐⭐⭐⭐⭐（出圈级工作，"AI 小镇"原始论文）
- **核心收获**：记忆流（Memory Stream）+ 反思 + 规划三件套。
- **为什么必读**：构建长程行为 Agent 的范本，对产品形态启发尤其大。

### 10. Voyager: An Open-Ended Embodied Agent with Large Language Models
- **作者 / 机构**：Guanzhi Wang, Jim Fan et al. / NVIDIA + Caltech + UT Austin
- **会议 / 年份**：TMLR 2024
- **影响力**：⭐⭐⭐⭐⭐（具身智能 + 终身学习的经典）
- **核心收获**：技能库自我成长 + 课程学习 + 环境反馈循环。
- **为什么必读**：理解"会自己变强的 Agent"应该长什么样。

---

## 第四梯队：评估与综述（建立全局观）

### 11. AgentBench: Evaluating LLMs as Agents
- **作者 / 机构**：清华大学 THUDM
- **会议 / 年份**：ICLR 2024
- **影响力**：⭐⭐⭐⭐
- **核心收获**：Agent 能力的多维度评测基准，做 Agent 必看的"考卷"。
- **为什么必读**：决定你的 Agent "好不好"的标尺，做研究和落地都绕不开。

### 12. Agentic Retrieval-Augmented Generation: A Survey on Agentic RAG
- **作者 / 机构**：综述（多机构）
- **会议 / 年份**：arXiv 2025
- **影响力**：⭐⭐⭐
- **核心收获**：把 RAG 从"被动检索"升级为"主动检索 + 推理"。
- **为什么必读**：快速建立 Agentic RAG 的全景图，省下读 N 篇分散论文的时间。

---

## 第五梯队：工业实用（Function Calling 与落地实践）

### 13. ToolACE: Winning the Points of LLM Function Calling
- **作者 / 机构**：Huawei Noah's Ark Lab et al.
- **会议 / 年份**：ICLR 2025
- **影响力**：⭐⭐⭐
- **核心收获**：Function Calling 数据合成与训练的工程方法论。
- **为什么必读**：工程导向，落地参考价值高。

### 14. Facilitating Multi-Turn Function Calling for LLMs via Compositional Instruction Tuning
- **作者 / 机构**：北大 + 阿里等
- **会议 / 年份**：ICLR 2025
- **影响力**：⭐⭐⭐
- **核心收获**：聚焦"多轮"工具调用这一真实痛点。
- **为什么必读**：构建企业级 Agent 必踩的坑，这篇有直接借鉴意义。

### 15. ToolSmith: A Multi-Agent Framework for Enterprise Tool Creation
- **作者 / 机构**：企业级框架论文
- **会议 / 年份**：arXiv 2025
- **影响力**：⭐⭐
- **核心收获**：企业场景下"让 Agent 自己造工具"的多 Agent 框架。
- **为什么必读**：工程视角，了解工具自动化生成的边界与现状。

### 16. The Next Wave Arrives - Agentic AI in Financial Services
- **作者 / 机构**：行业报告（金融）
- **会议 / 年份**：2024–2025
- **影响力**：⭐⭐
- **核心收获**：金融行业落地视角，监管、合规、可审计场景下的真实需求。
- **为什么必读**：补充行业纵览，看清 Agent 在受监管领域的可行边界。

## 第六梯队：2025 前沿（建议在前五梯队之后阅读）

> 这三篇代表了 2025 年 Agent 研究的三条主线：**自动化工作流 / 轻量持续学习 / Test-Time 推理范式**。

### 17. AFlow: Automating Agentic Workflow Generation
- **作者 / 机构**：Jiayi Zhang et al. / DeepWisdom + 港中文（深圳）+ 港大
- **会议 / 年份**：ICLR 2025
- **影响力**：⭐⭐⭐⭐⭐（2025 年自动化 Agent 工作流的代表作）
- **核心收获**：用 **MCTS（蒙特卡洛树搜索）自动生成并优化 Agent 工作流**，把"写 Prompt / 设计 Pipeline"的人工劳动转化为可搜索的优化问题。
- **为什么必读**：工程上做 Agent Pipeline 的同学必看；理论上是 ToT 思想在"工作流空间"的延伸；让弱模型也能跑出强模型效果。

### 18. Memento: Fine-tuning LLM Agents without Fine-tuning LLMs
- **作者 / 机构**：UCL + Huawei Noah's Ark Lab et al.
- **会议 / 年份**：arXiv 2025.08
- **影响力**：⭐⭐⭐⭐⭐（GAIA 验证集 87.88% Pass@3，新范式代表）
- **核心收获**：提出 **基于记忆的在线强化学习（M-MDP）**——不动 LLM 主体参数，仅训练一个 case-selection 策略来检索/复用过往经验。
- **为什么必读**：是 Reflexion → Voyager 这条"经验复用"主线在 2025 年的最新答案，对落地极友好（持续学习 + 低成本部署）。

### 19. Scaling LLM Test-Time Compute Optimally Can Be More Effective than Scaling Model Parameters
- **作者 / 机构**：Charlie Snell, Jaehoon Lee et al. / UC Berkeley + Google DeepMind
- **会议 / 年份**：ICLR 2025
- **影响力**：⭐⭐⭐⭐⭐（OpenAI o1 / DeepSeek-R1 等 reasoning model 浪潮的理论基础之一）
- **核心收获**：系统化研究 **"测试时算力 vs 训练时参数"的最优分配**——对很多任务，把算力花在推理时（采样、验证、修订）比堆参数更划算。
- **为什么必读**：理解 2025 年整个 reasoning model / test-time-compute 趋势的钥匙。

## 阅读建议

- **如果只读 3 篇**：CoT → ReAct → Reflexion，足以建立 Agent 的核心心智模型。
- **如果做研究**：第一、二、三梯队全读 + 第六梯队（17–19）跟踪前沿，重点关注方法的"消融实验"和"失败案例"。
- **如果做工程落地**：1 → 2 → 3 → 8 → 第五梯队 → **17（AFlow）+ 18（Memento）**，直奔 Function Calling、多 Agent 编排和最新轻量化范式。
- **如果做产品 / 行业研究**：9（Generative Agents）→ 10（Voyager）→ 16（Agentic AI in FS），看清"Agent 能做什么、价值在哪"。
- **如果想理解 2025 年 reasoning model 浪潮**：直接从 19（Test-Time Compute）切入。

## 字段说明

每篇论文统一包含以下字段，便于横向对比：

| 字段 | 含义 |
|---|---|
| 作者 / 机构 | 第一作者及所属机构（多机构合作时列前 2–3 个） |
| 会议 / 年份 | 顶会接收情况（NeurIPS / ICLR / ACL / UIST 等）或预印本年份 |
| 影响力 | ⭐ 数综合考虑引用量、社区讨论度、对后续工作的启发 |
| 核心收获 | 一句话讲清楚这篇论文最核心的方法或贡献 |
| 为什么必读 | 在你的阅读路径中，这篇论文承担什么角色 |
